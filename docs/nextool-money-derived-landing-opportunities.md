# NexTool Money derived landing opportunities

## Purpose

This document evaluates which Money intents deserve dedicated derived landing pages after the core calculators begin receiving impressions in Google Search Console.

The goal is not to create doorway pages. A derived landing should exist only when it can provide a distinct answer, examples, tables and calculator context for a specific intent that is too important to hide inside a generic calculator page.

## Creation criteria

Create a derived landing only when at least one of these is true:

1. Google Search Console shows impressions for the exact/near-exact query family.
2. Keyword Planner or SERP review shows meaningful volume or CPC.
3. The derived page can add a unique calculator view, table, or examples not already obvious on the parent page.
4. The page can link naturally back to the parent calculator and to at least one next-step Money tool.

## Required page structure

Every derived landing should include:

- one specific H1 matching the intent;
- calculator or calculator prefilled/contextualized above the fold;
- 3+ concrete examples;
- a comparison table;
- common mistakes;
- one next-step internal link;
- canonical self URL;
- hreflang PT/EN when both languages exist;
- no thin duplicate copy from the parent page.

## Recommended first build order

1. `percentage calculator for discounts`
2. `mortgage calculator with down payment`
3. `compound interest calculator with monthly contributions`
4. `marketing ROI calculator`
5. `retirement savings gap calculator`

Reason: these combine clear intent, monetizable context, strong internal linking and easy examples.
